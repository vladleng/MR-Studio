# MRS Stage 1d — 0.1e: запись и мониторинг

Ручная приёмка Windows 10/11 x64, родной ASIO driver. Запустить MoonRiverStudio.exe
из MR-Studio-0.1e-ASIO-Windows. CI проверяет файлы/ядро; hardware ещё нужно проверить.

1. Files → New project. Выбрать в Audio settings ASIO device, частоту проекта,
   buffer 128 (либо поддерживаемый driver размер), Outputs 1,2 и Input 1..64.
   Input 0 означает выключенный вход. Connect. Закрыть настройки.
2. + Track → выбрать дорожку → Arm track. В списке появится [R], кнопка станет Disarm.
   Monitor on: вход слышен в обоих основных выходах; Monitor off: мониторинг выключен.
   Индикатор Input dBFS продолжает реагировать при выключенном мониторинге.
   При аппаратном direct monitoring отключить Monitor в MRS, чтобы не слушать вход дважды.
3. Остановить/поставить на Pause, выключить Loop. Поставить playhead НЕ в ноль.
   Record (R). Для ещё не сохранённого проекта выбрать .mrsproject в диалоге Save.
   Записать 10–20 секунд: красная кнопка End rec и растущая область дубля на дорожке.
   Переключить Monitor во время записи: файл продолжает записываться.
4. End rec, Pause или Space завершают дубль на текущей позиции с Pause.
   Stop завершает дубль и возвращает playhead в ноль. WAV появляется в Audio рядом
   с .mrsproject, клип — на вооружённой дорожке с позиции начала и точной длиной.
   Нулевой дубль не создаёт пустой клип. Разоружить дорожку и выключить Monitor,
   затем Play: записанное моно слышно одинаково слева/справа.
5. Undo/Redo убирают/возвращают клип одним действием. Сам WAV остаётся на диске.
   Move/trim/split нового клипа работают как с импортированным WAV.
   Второй Record создаёт новый уникальный WAV и клип; предыдущий дубль остаётся.
6. Импортировать WAV той же частоты, записать вместе с его воспроизведением:
   в дубль должен попасть только вход, без подмешанной фонограммы.
   В начале клипов нет пустых/лишних участков из-за положений Pause/Stop.
7. Files → Save, закрыть, повторно открыть .mrsproject: импортированные и записанные
   клипы, edits и graph state сохранились; Play работает без повторного импорта.
   Папку Audio сохранить рядом с проектом: медиа пока внешние, пути абсолютные.
   Save As не копирует/переносит WAV. Схема .mrsproject не изменена.
8. Во время записи New/Open/Import/Save, редактирование, seek/loop и смена устройства
   блокируются; Monitor, End rec/Pause/Stop и закрытие доступны. При закрытии сначала
   завершается дубль, затем предлагается сохранить изменённый проект.
9. Проверить 100/125/150% scaling: три кнопки, Files, таймлайн и Audio settings видны.
   Cue-выходы (если выбрано больше двух) не получают входной мониторинг/моно дубль.
10. Если появляются предупреждения recording/input/disk, сообщить текст и условия:
    успешная CI не заменяет проверку реального ASIO. Пропадание входа/overflow
    завершает запись, валидная часть сохраняется без склейки временного разрыва.

Границы 0.1e: один mono input/одна вооружённая audio track; raw float32 RIFF WAV;
без resampling, RF64, loop recording, punch-in, stereo/multitrack recording, take lanes,
компенсации input/output latency, media consolidation и crash-recovery chooser.
Максимальный WAV меньше 4 GiB (~6.2 часа mono/48k); предел завершает дубль явно.
Существующий native gain 0.5 влияет на слышимое воспроизведение/мониторинг, не на WAV.
Arm/Monitor — состояние текущей сессии, при открытии проекта Arm сбрасывается.
