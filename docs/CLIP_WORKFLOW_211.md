# Работа с клипами — #211

Контракт реализации [#211](https://github.com/vladleng/MR-Studio/issues/211),
2026-10-17. Пользовательская приёмка этого объёма ожидается. #210 принят отдельно.

## Выделение и имена

Shift + клик добавляет audio/MIDI-клип к текущему выделению. Повторный Shift-клик
снимает его; это решается на mouse-up, чтобы Shift-drag выбранной группы по-прежнему
работал. Shift + рамка добавляет пересечения к прежней группе. Без Shift прежняя
семантика рамки/клика сохраняется. Выделение и preview не пишутся в проект/Undo.

Обычный drag сохраняет взаимные позиции, Alt-drag копирует группу существующей
атомарной командой. Shift во время drag сохраняет прежнее временное отключение
Snap; Shift не заменяет модификатор Alt. Duplicate сохраняет прежнюю семантику.

В контекстном меню есть Rename selected clips. Одному клипу присваивается введённое
имя; группе — base name + 01, 02, ... по порядку дорожек, затем позиции, затем ID
при совпадении. Одна команда Undo для группы; source WAV не переименовывается.
Cancel/пустое имя не меняет проект; устаревший диалог после изменения проекта
отклоняется. F2 остаётся прежней workspace-командой и не переназначается.

Выбранные клипы получают лёгкую заливку и прежний выделенный контур. На верхней
панели два инструмента: Pointer (1) и разрезание (3). По уточнению пользователя
иконка tool_split заменяет карандаш у инструмента (3); отдельная кнопка Split
убрана. Разовая команда Split остаётся в меню и по S. Значки верхней панели
уменьшены до 14 logical px, области нажатия сохранены. Карандаш tool_knife
остаётся в библиотеке для дальнейшего использования. Shortcuts/Space/focus сохранены.

## Audio fade in/out

В верхней части waveform выбранного audio-клипа находятся две ручки; drag меняет
длительность соответствующего fade в samples. Preview виден до отпускания мыши,
но не меняет проект или звук; release — одна команда Undo, Escape/focus loss —
отмена. Исходный клип и document identity проверяются перед commit. Сохраняется
действующий structural edit guard Stop/Pause; live-редактирование не добавлено.

Fade линейный по амплитуде, относительно видимых границ клипа. Длительности
независимы и находятся в [0, clip.length]. Zero fade нейтрален. Для N > 1 fade-in
даёт 0 на первом и 1 на N-м sample; fade-out симметричен и даёт 0 на последнем.
N = 1 обнуляет крайний sample. При перекрытии множители перемножаются. Это
перекрытие двух ramps одного клипа, не автоматический crossfade между клипами.

Move/copy сохраняют fades. Trim привязывает их к новым видимым краям и ограничивает
каждую длительность новой длиной. Split оставляет fade-in на левой, fade-out на
правой половине, ограничивая длиной половины; новые внутренние края без fade.
При разрезе внутри ramp его форма нормируется на оставшуюся половину: точная
прежняя огибающая через такой разрез не обещается. MIDI fades не получает.

Fade применяется к воспроизведению клипа до track FX, один коэффициент на sample
для всех его каналов. Resident/streamed PCM и общий engine для Studio/Live/имеющихся
offline consumers используют тот же Voice path. Source PCM, offset, recording
input/raw capture не изменяются; новый export/bounce workflow не вводится.
Callback не выделяет память, не обращается к UI/файлам и не использует locks.

## Persistence и lifetime

Core snapshot schema **26** добавляет AUDIOFADE (fade_in/fade_out) к clip state.
Старые snapshots 1–25 читаются с нулевыми fades; archive container version **1**
сохраняется. Миграция нужна для сохранения нового звукового параметра; старые
версии приложения schema 26 не читают. Исходные пользовательские проекты не
конвертируются тестами: проверки на fixtures/копиях.

Fades — Project Model через Application/ICommand, history и save/reopen.
Групповое переименование — metadata, не пересборка аудио. Изменения fade/history
сохраняют insert instances/PDC/editor lifetime через существующий retained path.

## Дополнение к принятому #210

Общий FX power — тот же InsertPowerButton размером **13×13**, что в строках FX,
расположен слева от имени Mixer channel. Hit bounds имени/rename исключают power;
поведение, mixed-state feedback и Undo не меняются. Это отдельная корректировка
по запросу пользователя при приёмке #210, не изменение plugin/audio workflow.

## Проверка

Адресные model/serialization/migration, trim/split/copy/Undo/SaveOpen, численная
проверка resident/streamed fades и allocations, затронутые routing/record/host
регрессии и JUCE GUI smoke. Реальные результаты, source/EXE и исключения — в #211.
ASIO/слух/physical DPI нельзя вывести из software fixtures.
