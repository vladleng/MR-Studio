# 0.2e — пользовательская проверка

Использовать копию проекта; схема 13. Дополнительные улучшения после Stage 4.

- [ ] Double click MIDI clip → выделить несколько нот → Musical edit...
- [ ] Quantize grid + Start only при strength 100%; Undo/Redo всей операции.
- [ ] Strength 50% перемещает ближе к сетке; 0% ничего не меняет.
- [ ] Length only и Start and length; обычная и triplet сетка.
- [ ] Scope Whole clip обрабатывает слышимые ноты; Selected — только выделенные.
- [ ] Transpose группы: интервалы сохраняются, pitch 0/127 не переполняются.
- [ ] Velocity Set/Add/Scale %, Length Set/Add/Scale %; минимум 1 tick.
- [ ] Trim/split clip, начало/конец, короткие/перекрывающиеся ноты.
- [ ] Play через ASIO/VST3, Save/reopen — результат и controllers сохраняются.
- [ ] Во время Play/Record Apply запрещено; неверный ввод не меняет проект.
- [ ] Масштаб Windows/читаемость dialog. Физический ASIO/mixed DPI отдельно.
