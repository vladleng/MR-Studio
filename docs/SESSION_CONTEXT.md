# MR Studio — краткий контекст сессии Codex

Это **навигационная памятка**, а не источник актуального статуса задач. Не перечитывай её повторно в той же сессии. Актуальные правила — `AGENTS.md`, требования — соответствующая GitHub Issue, факт реализации — код текущей ветки.

- **Репозиторий:** `vladleng/MR-Studio`. `main` — источник правил и спецификаций; разработка — в тематических ветках. Перед изменениями сверяй ветку, HEAD и diff. Не загружай весь `docs/` или все Issues.
- **Продукты:** MR Studio — DAW; MR Live — отдельное сценическое приложение с документом `.mrlive`, запускаемое из Home. Общие компоненты — Core, Engine, транспорт, ASIO, MIDI, модель проекта, граф и hosting плагинов. Не создавай независимый дублирующий backend; не считай планируемые интеграции реализованными.
- **Границы безопасности:** сохраняй Commands/Model, Undo/Redo, persistence и plugin lifetime. Audio callback — без новых аллокаций, блокировок и I/O. GUI — действующая система MR UDS, только в объёме задачи.
- **Рабочий процесс:** Issue-first; проверяй нужную спецификацию и затронутый код. Для багфикса — RED → GREEN и адресная регрессия. PASS CI не равен пользовательской приёмке; не закрывай Issues и не сливай PR в `main` без её разрешения.
- **Сборки:** Fast Core и релевантные контрактные тесты — раньше тяжёлых; Windows Studio Release — вручную для готового кандидата или обоснованной Windows-проверки. После FAIL сначала логи и адресная диагностика. Опрос Actions — не чаще раза в минуту. Версии Studio и Live независимы; точные правила — в `AGENTS.md`.
- **Указатели по требованию задачи:** сборки — `.agents/skills/mr-studio-build-test/SKILL.md` и `docs/CLOUD_DEVELOPMENT.md`; MR Live — `docs/MR_LIVE_NATIVE_INTEGRATION.md`; GUI — `.agents/skills/mr-unified-gui/SKILL.md`; RT — `.agents/skills/mr-realtime-audio-safety/SKILL.md`.

Не подгружай эти документы автоматически: открывай только относящиеся к текущей задаче фрагменты. За свежими номерами сборок, Issues и PR обращайся к GitHub **адресно**, если этого требует запрос.
