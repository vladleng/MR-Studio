# Локальная приёмка — исторический указатель

**Действующий процесс**: [CLOUD_DEVELOPMENT.md](CLOUD_DEVELOPMENT.md), [Build/Test Skill](../.agents/skills/mr-studio-build-test/SKILL.md), `.github/workflows/` и `tools/ci/`. Старые локальные Stage-checklists, run logs и команды из прежней версии этого документа **не являются действующей политикой**.

Локальный Windows-ПК используется для пользовательской приёмки release-артефакта и фактических ASIO/MIDI/DPI/vendor проверок. Артефакт распаковывается **в отдельную папку вне checkout**; запуск бинарников непосредственно из `build/` может затронуть сохранение проектов и диагностику из-за ограничений записи. Локальная сборка допустима, но результат не подменяет source/CI на GitHub.

Не публиковать сторонние SDK, закрытые плагины, токены и пользовательские WAV/NAM. Доказательства по конкретной задаче фиксируются в Issue/PR/Actions, а не новым `FIX*.md`.

Исторические команды, результаты тестов и версии доступны в истории Git.
