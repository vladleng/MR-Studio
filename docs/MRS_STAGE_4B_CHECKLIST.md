# 0.2b: пользовательская проверка

Использовать копию проекта: Core schema 12 не открывается в сборках schema 11.
Билд и пакет указаны в [PROJECT_CONTEXT](PROJECT_CONTEXT.md).

- [ ] Подключить ASIO, создать instrument track и назначить SWAM или другой VST3.
- [ ] Выбрать дорожку и Edit → Create MIDI clip at cursor. Add note: pitch 60,
      Start 0, Length 1, velocity 100, channel 1. Play — есть звук без живой игры.
- [ ] Add ещё две ноты с Start 1/2 и другими pitch. Выбор/Apply/Delete изменяет
      нужную ноту; Undo/Redo возвращает результат. Velocity 0 отклоняется.
- [ ] Двойной щелчок по клипу открывает редактор; после Apply окно остаётся видно.
- [ ] При Stop/Play/Pause/seek внутрь длинной ноты нет зависших нот; seek внутрь
      восстанавливает её звучание. Тон/канал соответствуют редактору.
- [ ] Передвинуть клип, обрезать края, Split на курсоре внутри клипа. Duplicate
      создаёт копию справа; Delete и Undo работают. MIDI нельзя бросить на audio/bus.
- [ ] Edit → Loop selected clip: несколько витков не накапливают зависшие ноты,
      ноты у края клипа обрезаются. Снять loop через транспорт.
- [ ] Transport → Project tempo: например 120 → 60. Музыкальная длина клипа
      и расположение относительно сетки сохраняются, время звучания меняется.
- [ ] Save/закрыть/open: ноты, MIDI clips, instrument state и route сохранены.
- [ ] Process Buffer Off/1024/4096 и Workers 1/2/4: playback и живой MIDI работают
      вместе с аудиодорожкой. Проверить выбранный рабочий режим ASIO на слух.

Запись MIDI и полный piano roll относятся к следующим подэтапам.
Перечисленные пункты не считаются пройденными по одному automated PASS.
