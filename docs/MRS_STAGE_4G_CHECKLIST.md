# 0.2g — внешний MIDI: пользовательская проверка

Локальная реализация не означает физическую приёмку Stage 4g или всего Stage 4.

1. Создать инструментальную дорожку. В Arrange нажать кнопку MIDI-входа/статуса:
   External MIDI output → внешний порт; Output channel → Original или 1–16.
   VST3 необязателен. Аудио внешнего синтезатора возвращать через обычную аудиодорожку.
2. Выбрать MIDI input и включить мониторинг I: клавиатура передаёт ноты, velocity,
   sustain, bend, CC и Program Change. Monitor off выключает thru, но не запись.
   Отключить MIDI echo синтезатора: сложные кабельные петли автоматически не определяются.
3. Проиграть MIDI-клип, проверить выбранный канал, смену темпа, loop, Seek,
   Pause/Stop, Mute/Solo и Panic. Проверить отсутствие зависших нот.
4. Отключить/вернуть порт: missing/unavailable/connected отражаются в статусе.
   Reconnect делать при Stop/Pause. После возврата Seek/Play восстанавливает
   held playback; бесшовного восстановления live удержанных клавиш нет.
5. Undo/Redo назначения, Save/Open и открытие старого проекта. Сохранять копию:
   схема 14 не открывается предыдущими сборками; 0.2g читает схемы 1–13.
6. Совместно проверить внешний MIDI, VST3 и audio return, запись audio/MIDI,
   ASIO 64/128/256 frames и Process Buffer Off/On. Оценить timing на реальном
   устройстве: WinMM/USB/DIN jitter не является sample-accurate и не калибруется автоматически.

Контракт и ограничения: [MIDI_EXTERNAL.md](MIDI_EXTERNAL.md).
После приёмки — совместная проверка Stage 4, без автоматического начала Stage 5.
