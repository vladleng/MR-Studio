# MR Studio / MR Live — версионирование

**Канонические действующие правила** находятся в [AGENTS.md, «Правила версирования для сборок, Issues и Sub-issues»](../AGENTS.md#правила-версирования-для-сборок-issues-и-sub-issues).

- MR Studio и MR Live имеют независимые версии.
- `fixN` — исправление текущей версии, `UpdN` — небольшое дополнение в пределах Sub-issue; неудачный CI запуск сам по себе версию не повышает.
- Совпадение версий приложения, Actions run и артефактов регулируется AGENTS и исполняемыми workflow.
- PASS CI не подтверждает пользовательскую приёмку и не разрешает merge.
- Историческое соответствие старых `0.1`–`0.3` сборок/этапов/Issue находится в истории Git, Issue и PR, а не в параллельном журнале.

Не добавлять сюда таблицу текущих сборок: статус и историю решений фиксировать в конкретной Issue.
