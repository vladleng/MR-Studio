Единственный постоянный вход — корневой [AGENTS.md](../AGENTS.md). Актуальная задача и приёмка — в GitHub Issues (CLOUD) или DSH Task Manager (LOCAL); реализованное поведение — в коде и тестах активного режима. Если нужен технический контракт, используй [индекс docs](README.md).
