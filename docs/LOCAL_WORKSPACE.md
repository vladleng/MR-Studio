# Local Workspace — исторический указатель

Разработка MR Studio/MR Live ведётся через GitHub. Действующие правила — [AGENTS.md](../AGENTS.md) и [CLOUD_DEVELOPMENT.md](CLOUD_DEVELOPMENT.md). Прежние local-only каталоги, сборки и инструкции из истории этого файла не переопределяют действующую CI-политику.

**Для пользовательской Windows-приёмки:** разворачивать собранный artifact отдельно от checkout; выполнять реальные ASIO/MIDI/DPI/vendor проверки по конкретной Issue. Не изменять пользовательские проекты и настройки в рамках подготовки тестов.

Старый журнал локального workspace доступен в Git history.
