   4. etc

# Меню ПКМ по области патча

- + Patch (создает патч, который автоматически захватывает последнее состояние параметров плагина или всех плагинов на канале)
- Rename
- Delete
- Update
- Replace
  - Plytone
  - RC J120
  - Marshall
  - etc

# Меню ПКМ по области Sub-Patch

- + Sub-Patch
- Rename
- Delete
- Update

# Условия

1. При создании патча в нем на всем его проятжении появляется sub-patch default, который по сути является первым созданным sub-patch и который можно переименовать или изменить.
2. При нажатии ЛКМ на блоке sub-patch появляется выпадающее меню со списком саб-патчей для этого патча.
3. Сбоку от названия саб-патча появляется звездочка, если параметры были изменены, но не сохранены через update.
4. Если был добвлен или удален какой-нибудь плагин на канале и сохранен через update в патче - его параметры для сохранения становятся доступны для всех саб-патчей этого патча.
5. ПКМ по пустому треку открывает меню:
	- + Patch
	- Default
	- Polytone
	- RC J120
	- etc


Все назавния патчей и саб-патчей в меню даны для примера их создавать не нужно, кроме default
