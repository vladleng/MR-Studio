MR Studio — полный SVG-каталог

Онлайн-каталог SVG из репозитория vladleng/MR-Studio. Работает из браузера через GitHub Pages, не требует установки, скачивания или клонирования.

Список загружается из актуального дерева GitHub, изображения — напрямую из GitHub Raw. Нажми на карточку для увеличения и перехода к исходнику. Данные только для просмотра; интерфейс DAW не изменяется.
